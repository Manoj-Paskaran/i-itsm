# Ticket data provenance

`synthetic-tickets.jsonl` is generated by `scripts/generate_synthetic.py`: 300 unique
symptom × service × phrase × noise combinations per category, seed 42. It is
training data only, not the source of validation/test examples.

Public source: [KameronB/synthetic-it-callcenter-tickets](https://huggingface.co/datasets/KameronB/synthetic-it-callcenter-tickets), Apache-2.0 as declared by its dataset card.
This is independently generated synthetic data, not verified real incident data.
Download with `uv run python scripts/fetch_data.py tickets`. Revision and SHA256
are pinned in `tickets-provenance.json`; raw CSV remains ignored in `data/raw/`.
No customer/email columns are retained in model inputs: only short_description
and content. Source product metadata and broad source categories provide weak
labels; see `PRODUCT_RULES` and `CATEGORY_MAP` in `scripts/train_classifier.py`:

- Identity/PIV/MFA products and ACCOUNT → authentication.
- PostgreSQL/SQL/Oracle Database/MongoDB/BigQuery/Databricks → database.
- ShareFile/Dropbox/OneDrive/backup/storage/NAS/NetApp → storage.
- Security/antivirus products and SECURITY → security.
- Network/VPN/router products and NETWORK → network.
- Kubernetes/AWS/Azure/cloud/OpenShift/Terraform/GCP → cloud.
- Printer/laptop/monitor/keyboard/desktop and HARDWARE/PRINTER → hardware.
- Business apps (Salesforce/SAP/Workday/ServiceNow/Dynamics/Tableau/Power BI/Asana/Trello) and EMAIL → application.
- Remaining SOFTWARE → software; other labels are excluded.

First matching product rule wins. This explicit, imperfect taxonomy mapping is a
limitation, not expert-annotated ground truth. Deduplicate normalised text before
stratified splits (seed 42), cap source sampling at 160 per class, split the public
source 60/20/20, and add templates only to training. Keep the held-out source
separate from local generator examples. No third-party raw rows are committed.
Gemini-generated top-up is optional and blocked until a key is supplied.

## UCI SLA risk data

Dataset 498: Incident Management Process Enriched Event Log, DOI 10.24432/C57S4H,
CC BY 4.0. `scripts/fetch_data.py uci` saves the exact source URL and SHA256 in
`uci-provenance.json`; raw ZIP/CSV are ignored. Snapshot features are selected
explicitly before preprocessing. No closed/resolved state rows or closure metadata
are model inputs. Split by incident number, including calibration folds, never by
rows. See the ML-2 report for mapping and resolution-policy assumptions.
